1系统概述

GeoVIO 是一套面向无人机相对导航的全数字仿真验证环境。核心功能为 视觉/惯性组合导航（Geo-VIO）：利用机载航拍影像与卫星基准图进行地理配准，结合 IMU 数据经误差状态扩展卡尔曼滤波（ESEKF）融合，实现无 GNSS 条件下的绝对定位与相对导航解算，并通过 PyQt5 图形界面完成全流程仿真与可视化。

整体功能链路

1数据预处理航拍图像去雾 / CLAHE 增强，提升配准质量
2视觉定位航拍图与卫星底图 LoFTR 配准 + PnP 解算绝对位置
3信息融合IMU 预测 + 视觉量测经 ESEKF 滤波输出平滑轨迹
4相对导航主从机 TCP 通信，按距离/方位/仰角解算僚机位置
5后置处理轨迹对比、误差统计、配准结果回溯分析

核心模块清单

模块路径功能
仿真主界面main_window.py三域组织的 PyQt5 入口，管理全部子窗口
导航流水线vio.pyEKFWorker 线程逐帧执行 IMU 预测 → 配准 → PnP → EKF 融合
滤波器ESEKF_IMU/误差状态扩展卡尔曼滤波（predict / update）
视觉定位visual_localization/DINOv3 粗对准、LoFTR 配准、PnP-RANSAC + LM 精化
图像预处理preprocessing/CNN 去雾（dehaze）、CLAHE/gamma 增强（enhance）
相对导航relative_navi/主从机 TCP 仿真：server 广播轨迹，client 解算相对位置
统计分析stats_analysis/逐帧误差统计图、配准统计表、匹配结果浏览

2环境安装

2.1 创建 conda 环境

# 创建并激活 Python 3.10 环境
conda create -n geovio python=3.10
conda activate geovio

# 安装 PyTorch（CUDA 12.8 版本）
pip install torch==2.7.1 torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128

# 安装项目依赖
pip install -r requirements.txt

2.2 硬件要求

  • 推荐：NVIDIA 显卡 + 支持 CUDA 12.8 的驱动，DINOv3 / LoFTR / 去雾均在 GPU 上运行。
  • 无 GPU：去雾功能不可用（代码强制 .cuda()）；LoFTR 与 DINOv3 自动退化到 CPU，速度显著下降。

5快速启动

5.1 常规启动

conda activate geovio
python main_window.py

bash start.sh
start.sh 内部直接调用 ~/miniconda3/envs/geovio/bin/python 启动主界面，无需手动激活 conda 环境。若 conda 安装路径不同，请修改脚本中的 Python 路径。

  1. 确认 configs/base.yaml 中数据集路径、DEM、底图路径正确；
  2. 确认 DINOv3 权重已放入 visual_localization/ckpt/（或将 rotation_angle 设为固定值）；
  3. 可先设 DEBUG: True 跑前 30 帧验证链路，再放开全序列。

8导航流水线原理

vio.py 中 EKFWorker 在独立 QThread 中逐帧处理航拍影像（*.tif + 同名 GBK 编码 *.txt 元数据），每帧执行以下流程：

1IMU 预测解析元数据 IMU 量测，ESEKF 传播位姿 → ENU 预测位置
2粗对准首帧用 DINOv3 特征余弦相似度确定旋转角（0/90/180/270°）
3底图裁剪按视场覆盖范围在金字塔中选取层级并裁剪对应区域
4LoFTR 配准无特征点匹配 + RANSAC 单应 + 四边形几何校验
5PnP 解算匹配点经 DEM 转 ECEF，PnP-RANSAC + LM 精化得绝对位置
6EKF 融合偏差 < 门限则量测更新，否则仅用 IMU 预测保证连续
7结果输出轨迹 CSV、匹配点 npy、配准统计、运行日志

8.1 配准有效性校验

LoFTR 匹配经 findHomography（RANSAC）后做四边形几何校验，任一不满足即丢弃该帧视觉量测：

  • 内点数 ≥ register_min_inliers 且内点比例 ≥ register_min_ratio；
  • 投影四边形必须为凸形、面积不超底图、长宽比 ≤ 3、内角在 45°–135° 之间；
  • PnP 位置与 IMU 预测距离 ≤ ekf_fusion_threshold 才进行 EKF 量测更新。

8.2 融合策略

  • 匹配失败 / PnP 失败 / 超门限 → 采用 IMU 预测位置，轨迹不中断；
  • 视觉量测生效帧计入 n_vio，结束时打印 VIO 占比；
  • 所有量测均投影到首帧经纬度定义的 ENU 局部坐标系处理。

9相对导航联调（relative_navi/）

主从机 TCP 通信仿真，验证相对导航解算链路。

9.1 部署步骤

  1. 主从两台机器分别配置相同 conda 环境并 pip install -r relative_navi/requirements.txt；
  2. 配置局域网保证互相 ping 通；
  3. 检查 server.py 开头的数据文件路径：enu_datum.txt（ENU 基准点 lat lon h）与 traj_esekf_out_f1.txt（轨迹：timestamp x y z qx qy qz qw）；
  4. 修改 client.py 中 SERVER_IP 为主机实际局域网 IP；
  5. 先启动主机 server.py，再启动从机 client.py。

9.2 启动命令

# 主机（端口 50007，0.5 s 周期广播 ECEF 位置）
python relative_navi/server.py

# 从机
python relative_navi/client.py

9.3 工作原理

  • server.py：逐点读取 ENU 轨迹 → 经 enu_datum 基准点转 ECEF → JSON 行式 TCP 发送（{"timestamp":…, "position":[x,y,z]}）；
  • client.py：接收主机位置后，以随机距离（600–800 m）、方位角（110–120°）、仰角（±10°）在 ENU 系构造僚机偏移并转回 ECEF，即相对导航解算；
  • 可视化：OpenCV 窗口显示主机（红点）与僚机（蓝点）相对初始位置的经纬度偏移，按 q 退出。

13常见问题

现象排查 / 处理
